# Evalution of LLM

## Evaluation of the RAG System (RAGAS Framework)

The evaluation aims to assess the accuracy of our RAG (Retrieval-Augmented Generation) system in classifying occupation codes. To achieve this, utilize a dataset from the Hugging Face repository as **test_data**, which contains 7,000 **occupations as queries** along with their corresponding **ground truth ISCO codes**.

**To access the test_data;**

Navigate to Github repositry (LLMS-Project): *Data/test_data/isco_occupations_Test_data.csv* or 
Use Huggingface repository link:*https://huggingface.co/datasets/ICILS/isco_esco_occupations_taxonomy*






Before proceeding with the evaluation, **enhance the dataset** by adding two additional columns:

**. Generated_answer** – The ISCO codes generated by the RAG system.

**. retrieved_docs** – The retrieved contextual information used in generating the ISCO codes.

These additions are necessary because the **RAGAS framework** requires the following components for evaluation:

1. Queries (Occupation descriptions)
2. References (Ground truth ISCO codes)
3. Generated Answers (RAG-predicted ISCO codes)
4. Retrieved Contents (Contexts retrieved by the RAG system)


## Evaluation Approach

The evaluation of the RAG system focuses on two key aspects: Retrieval and Generation.

**1. Retrieval Evaluation**

To assess the effectiveness of the retrieval system, we use the **Context Recall metric**. This metric measures how accurately the RAG system retrieves relevant content by comparing the Query with the RAG Retrieved Contents. A higher recall indicates that the system effectively retrieves relevant contextual information necessary for classification.

**2. Generation Evaluation**

For evaluating the response generation, focus on two key metrics:

**. Answer Correctness** – Measures how accurately the generated ISCO codes match the ground truth references.

**. Faithfulness – Assesses** – Measures whether the generated ISCO codes are factually consistent with the retrieved contexts, ensuring that the system does not generate misleading or unsupported classifications.
